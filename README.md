# StyleOS ✨ — Personal AI Fashion Architect

**StyleOS** is a next-generation web application designed to help users discover subculture style identities, curate daily outfits, and organize dynamic wardrobe items.

---

## 🚀 Live Demo & Links

* 🌐 **Live Preview:** [https://capstone-app-kohl.vercel.app](https://capstone-app-kohl.vercel.app)
* 🐙 **GitHub Repository:** [https://github.com/UnzishMaira/capstone-app](https://github.com/UnzishMaira/capstone-app)

---

## 🛠️ Architecture & Tech Stack

* **Framework:** Next.js 14 (App Router)
* **Styling:** Tailwind CSS
* **Deployment Pipeline:** Vercel Continuous Deployment (CI/CD)
* **Language:** TypeScript / React

---

## 📱 Feature Map & Application Routes

| Route | Description |
| :--- | :--- |
| `/` | **Dashboard:** Overview of fashion archetypes & navigation hub |
| `/quiz` | **AI Style Quiz:** Interactive questionnaire to match fashion subcultures |
| `/aesthetics` | **Subculture Vault:** Exploration of Goth, Y2K, Emo, Modern Chic & Desi Fusion |
| `/planner` | **Weekly Style Calendar:** Day-by-day look scheduling |
| `/occasions` | **Event Styling:** Attire & jewelry recommendations by event type |
| `/wardrobe` | **Digital Closet:** Real-time apparel and accessory inventory management |
| `/health` | **System Health Check:** Server-side API verification payload |

## 💻 Local Setup & Installation

1. **Clone the repository:**
   ```bash
   git clone [https://github.com/UnzishMaira/capstone-app.git](https://github.com/UnzishMaira/capstone-app.git)
   cd capstone-app

   ```

   Install dependencies:
   npm install

   Run development server:
   npm run dev

  ## Open http://localhost:3000 in your browser.
